Convenção: todos os comandos abaixo assumem que você está dentro da respectiva
pasta em common/ (ex.: cd common/sadcloud/sadcloud). Por padrão, todos os
serviços apontam para o TRAINING_SET. Para rodar contra o TEST_SET, defina as
variáveis de ambiente TFVARS_DIR / OUT_DIR antes do comando, como mostrado na
seção "Rodando contra o test_set" no fim deste arquivo.

#sadcloud (a partir de common/sadcloud/sadcloud)

docker compose run --rm --entrypoint sh terraform -c "sh /scripts/run_specific_plan.sh noncompliant-complex-05.tfvars"
docker compose run --rm --entrypoint sh terraform -c "sh /scripts/run_show_all.sh"

#     docker compose run --rm --entrypoint sh terraform -c "sh /scripts/run_plans.sh"
#
#   (a partir de common/checkov)
#   TFVARS_DIR=../../test_set/sadcloud/tfvars OUT_DIR=../../test_set/checkov/out \
#     docker compose run --rm checkov -c "sh /scripts/run_checkov_all.sh"
#
#   (a partir de common/infracost)
#   TFVARS_DIR=../../test_set/sadcloud/tfvars OUT_DIR=../../test_set/infracost/out \
#     docker compose run --rm --entrypoint sh infracost -c "sh /scripts/run_infracost_all.sh"
#
#   (a partir de common/llm)
#   TFVARS_DIR=../../test_set/sadcloud/tfvars OUT_DIR=../../test_set/llm/out \
#     docker compose up --build
#
# Os extratores (extrator_checkov.py, extrator_infracost.py, extrator_llm.py)
# e os geradores de análises: troque "../../training_set" por "../../test_set"
